## 👨‍💻 About Me

Hello! I'm **Arisa Akiyama**, a passionate software developer focused on building fast, modern, and beautiful desktop and web applications.

- 🚀 Creator & Maintainer of **[Yomic](https://github.com/ArisaAkiyama/yomic)** — Open-source Desktop Manga Reader.
- ⚡ Specialized in **C#**, **.NET**, and **Avalonia UI** cross-platform development.
- 🎨 Loving clean code, modern dark interfaces, and rich user experience.
